# astrbot_plugin_goodluck · 今日运势

> 一条指令，看看今天适不适合出手。🍀

AstrBot 娱乐插件：发送 `/今日运势`，机器人给出 **0~100 的运势指数**、**今日宜 / 今日忌**、
一句 **今日建议**，以及 **幸运数字 / 幸运颜色 / 幸运方位 / 黄金时段**。

- 🔒 **完全本地计算** —— 不调用 LLM，不需要 API Key，不依赖任何第三方库，秒回。
- 📅 **结果当天固定** —— 同一个用户在同一天里重复查询，拿到的结果完全一致，刷不出高分。
- 💬 **私聊群聊都支持** —— 群聊里可以自动 @ 你，也可以关掉。

> **为什么输出里一个 emoji 都没有？**
> 部分客户端（如 QQ / NapCat）的字体缺少 emoji 字形，会把 emoji 渲染成豆腐块 `□`。

> 外加 `━ █ ░ ✓ ✗` 五个在 QQ 上实测可正常显示的制表符 / 钩叉符号。

## 安装

### 方式一：插件市场

AstrBot 面板 → **插件市场** → 搜索 `今日运势` 或 `goodluck` → 安装。

### 方式二：从仓库链接安装

AstrBot 面板 → **插件管理** → 安装插件 → 从链接安装，填入本仓库地址：

```
https://github.com/10XuQ/astrbot_plugin_goodluck
```

### 方式三：手动安装

把整个仓库文件夹放进 AstrBot 的 `data/plugins/` 目录，然后在面板里重载插件。
没有 `requirements.txt`，**不需要安装任何依赖**。

```
AstrBot/
└── data/
    └── plugins/
        └── astrbot_plugin_goodluck/
            ├── main.py
            ├── metadata.yaml
            ├── _conf_schema.json
            ├── logo.png        # 图标（由 logo.svg 渲染而来）
            ├── logo.svg        # 矢量源文件，可自行改色改字后重新导出
            └── README.md
```

装完在面板 **插件管理** 里看到 `今日运势` 就成功了。

## 使用

默认唤醒前缀是 `/`，发送下面任意一条即可（三个词完全等价）：

| 指令 | 说明 |
| --- | --- |
| `/今日运势` | 主指令 |
| `/今日运气` | 别名 |
| `/gl` | 别名（good luck） |

> **群聊注意**：AstrBot 默认不会响应群里的每条消息，需要 **@机器人** 或带上唤醒前缀，
> 例如 `@Bot /今日运势`。

## 配置

在 AstrBot 面板 → 插件管理 → `今日运势` → 配置 里修改，保存后即时生效。

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `reply_with_at` | bool | `true` | 群聊中回复时是否 @ 发送者。私聊不受影响。 |

## 它是怎么算出来的？

运势不是真随机，也不是玄学，而是一个 **可复现的伪随机**：

```python
# main.py
day = datetime.now().strftime("%Y-%m-%d")
digest = hashlib.sha256(f"goodluck::{seed_text}::{day}".encode()).digest()
return random.Random(int.from_bytes(digest, "big"))
```

其中 `seed_text` 是发送者的用户 ID（拿不到时退化为会话标识 `unified_msg_origin`）。

- 种子只由 **用户 ID + 当天日期** 决定，所以 **同一天同一用户结果恒定**，换个人或换一天就完全不同。
- 用的是 `hashlib.sha256` 而不是 Python 内置的 `hash()` —— 后者受 `PYTHONHASHSEED` 影响，
  进程重启后结果会漂移，用它就做不到「当天固定」了。
- 分数用 `rng.randint(0, 100)` 均匀抽取，没有暗改概率：**大吉大凶一样稀有，也确实抽得到**。

## 常见问题

**Q：为什么我连发几次，结果一模一样？**
这是设计如此。种子来自「用户 ID + 日期」，同一天内恒定，避免反复刷到满意为止。第二天 `00:00` 自动翻篇。

**Q：机器人没反应？**
群聊里默认需要 @机器人 或者消息以 `/` 开头。另外确认面板里插件已启用、没有报错。

**Q：想改文案 / 加词条？**
直接改 `main.py` 里的 `GOOD_ACTS`、`BAD_ACTS`、`ADVICES` 等列表即可，都是纯文本常量。

**Q：分数好低，是不是坏了？**
`0~100` 均匀分布，20 分以下本来就有约 20% 的概率。多测几天就平了。
